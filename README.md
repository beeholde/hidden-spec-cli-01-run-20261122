`mend` is a single command-line tool that applies the edits AI models write, in
four formats (unified diff, SEARCH/REPLACE, V4A, JSON), to a tree of files.
Node 22, standard library only. Entry for the
[make.fun bounty hidden-spec-cli-01-run-20261122](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).
